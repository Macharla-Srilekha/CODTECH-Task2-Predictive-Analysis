# CODTECH-Task2-Predictive-Analysis
Data Analyst Internship Task 2 - Predictive Analysis using Machine Learning on Student Performance Dataset 

## Project Title:
Predictive Analysis using Machine Learning

## Objective:
To predict student exam scores using machine learning based on multiple features.

## Dataset Features:
- study hours
- attendance
- sleep hours
- internet usage
- assignments completed
- previous score

## Target Variable:
- exam score

## Machine Learning Model:
Linear Regression

## Steps Performed:
- Data loading
- Feature selection
- Train-test split
- Model training
- Prediction
- Evaluation

## Evaluation Metrics:
- Mean Squared Error (MSE)
- R2 Score

## Visualizations:
- Actual vs Predicted graph
- Error distribution graph

## Outcome:
Successfully built a predictive model to estimate exam scores.

## Tools Used:
- Python
- Google Colab
- Pandas
- Scikit-learn
- Matplotlib
